## 1. 定位
轻松解压、带适度顺序推理的箭头解谜单机网页游戏。核心循环：观察棋盘 → 选择箭头 → 箭头滑出 →
机关变化 → 继续疏通 → 清空通关。无强制倒计时、生命值、扣分；允许试错，提供无限撤销、重开、提示。
电脑 + 手机浏览器，鼠标 / 触摸 / 基本键盘；localStorage 本地存档；运行不依赖 AI API。

## 2. 核心规则（摘要）
- 矩形网格宽 5~7、高 3~7；每关 3~12 支直线箭头，占连续 1~3 格，方向上/下/左/右。
- 数据记录头部坐标、方向、长度、可选机关组；箭身从头部沿朝向反方向推导。
- 初始箭头之间、箭头与闸门不重叠、不越界；点头部或箭身选中同一支。
- 只能沿朝向整体平移离场；移动前检查完全离场路径；其他箭头与关闭闸门阻挡，自身原占用格不算障碍，开启闸门可通过。
- 被阻挡保持原位、突出阻挡物，不扣分、不改机关、不进撤销历史。
- 开关箭头成功离场后切换同组所有闸门一次；每支开关只属一组；每关最多两组、合计最多 4 闸门格；
  用符号（◇/○）加颜色区分；先按移动前门状态校验，成功离场后才切换；不能靠自己的门穿过原本关闭的门。
- 所有箭头离场即通关，闸门不用清除；最后一支离场后即使关门也通关。
- 机关预览：电脑悬停 / 键盘聚焦开关突出关联闸门并说明将开启/关闭；手机“查看机关”模式点击只预览不移动。

## 3. 离场动画（必做）
整支沿朝向连续滑动到尾部完全出界才移除；普通 250~450ms；动画期间禁用重复移动/撤销/重开/切关/提示；
顺序：校验 → 存快照 → 动画 → 一次性提交移除+切换 → 存稳定存档 → 判通关 → 释放锁；完成逻辑只执行一次；
处理取消、尺寸变化、减少动态；动画中刷新恢复上一稳定状态；最后一支动画完成后才显示通关。

## 4. 辅助与存档
无限撤销（恢复箭头+闸门+运行状态，空历史禁用，被阻挡不进历史，通关后可撤销但不收回解锁）；
重开恢复初始布局+门状态+空历史，保留完成/解锁；提示基于当前状态搜索完整解法，突出“执行后仍可通关”的箭头，
无解时即使有局部可移动也提示撤销/重开；localStorage 存完成/解锁/当前关卡/稳定状态/撤销历史，带版本与校验，
坏档/过期/不匹配/存储不可用安全回退不白屏，写入失败仍可玩但提示。

## 5. 关卡
12 个原创固定关卡：1~3 普通；4~6 一组开门；7~9 关门前顺序；10~12 两组组合。每关稳定 ID + 设计目标 +
校验 + 至少一条引擎重放解法。固定回归样例（宽5高3：A(0,0)右◇、B(0,2)右、C(2,2)上、◇门(3,2)初开）用于测试夹具。
追加（2026-11-16 用户指令「再多创建机关关卡」）：新增 l13~l18 六个机关关（13~15 单组进阶、16~18 双组进阶），
总数 18；基线 12 关梯度与规则不变，新增关同样经校验 + 引擎重放。见 decisions.md D11。

## 6. 界面
入口（名称/开始继续/选关/玩法说明）、游戏（关卡名/棋盘/撤销/重开/提示/查看机关/返回）、通关（反馈/下一关/重玩/返回）、
选关（已完成/已解锁/未解锁）。简洁柔和、棋盘为视觉中心；手机触摸目标约 44px；适配 360/390/桌面；控件可访问名称 +
键盘聚焦触发 + 动态结果可访问通知。
